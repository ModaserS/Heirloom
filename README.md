# Heirloom

Heirloom is a platform for capturing family cooking knowledge,
preserving recipe origins, and sharing trusted recipes.

Status: planning and initial setup. Features below are planned.

## Who it is for

People learning family dishes, collecting relatives’ recipes,
and preserving the stories and knowledge behind them.

## First release

- User accounts and private recipe creation, editing and deletion
- Recipe photographs and personal cookbooks
- Family invitations and shared recipes
- Family profiles and a tree connecting people to their recipes
- AI-assisted handwritten and voice recipe imports
- Editable AI drafts reviewed before saving

## Longer-term direction

- Recipe histories and attributed adaptations
- Creator-published recipes with clearly defined approval signals
- Public cookbooks and community cooking results

## Planned stack

- Next.js, React and TypeScript
- Python and FastAPI
- PostgreSQL hosted on Supabase
- Supabase Authentication and Storage
- Automated testing and GitHub Actions

## First technical milestone

Run the frontend and backend locally, connect a frontend page
to the API health endpoint, and add automated checks.
